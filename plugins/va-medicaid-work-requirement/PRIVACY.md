# Privacy Policy: VA Medicaid Work Rule Guide (unofficial)

**Effective date:** September 26, 2026

This policy covers the `va-medicaid-work-requirement` plugin ("the plugin"), maintained by [@koongipaloongi](https://github.com/koongipaloongi).

## Summary

The plugin **does not collect, store, sell or share any personal information**. It has no server, no database, no analytics and no tracking. The maintainer never receives what you type.

## What the plugin is

The plugin is a set of instructions (skills) and reference files. It runs entirely inside Claude, on claude.ai, in Cowork, or in Claude Code. It contains:
- no code that sends data anywhere
- no MCP servers or connectors
- no hooks or scripts that run automatically

## What happens to what you type

When you use the plugin, your messages and anything you paste (for example, a Medicaid letter) are processed by Claude like any other conversation. **Anthropic handles that data under its own privacy policy**, not this one: https://www.anthropic.com/legal/privacy

The plugin itself:
- **Doesn't ask for** names, Social Security numbers, Medicaid ID numbers, case numbers, dates of birth or addresses.
- **Tells you to remove** those details before you paste a letter, and doesn't repeat them back if they're left in.
- **Doesn't save anything to a file.** The one exception: in Claude Code, `hours-tracker` saves a log if you ask it to. The log holds only months, activity types, hours and dollar amounts, and it's saved on your own computer.

## Links to other sites

The plugin links to official sites such as dmas.virginia.gov, coverva.dmas.virginia.gov, dss.virginia.gov and virginialawhelp.org. Those sites have their own privacy policies.

## Children

The plugin isn't meant for people under 18.

## GitHub issues

If you report a problem through [GitHub issues](https://github.com/koongipaloongi/skills/issues), your report is **public**. Don't include personal or case details.
